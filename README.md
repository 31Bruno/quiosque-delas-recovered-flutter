# Quiosque Delas — Código Recuperado

## Sobre o Projeto

O **Quiosque Delas** era um sistema desenvolvido para disponibilizar um cardápio digital e permitir que os clientes enviassem seus pedidos diretamente ao balcão da empresa.

O projeto tinha como objetivo facilitar a visualização dos produtos do cardápio e agilizar o processo de envio de pedidos.

O sistema foi descontinuado devido à empresa não necessitar mais da solução.

## Funcionalidades

- Visualização do cardápio digital.
- Seleção de produtos para realizar pedidos.
- Envio de pedidos diretamente ao balcão.

*As funcionalidades acima descrevem a finalidade original do sistema.*

## Recuperação do Código

Este repositório contém arquivos obtidos a partir do APK Android do aplicativo, utilizando o [Blutter](https://github.com/worawit/blutter), uma ferramenta para análise de aplicativos Flutter compilados com Dart.

## Informações Técnicas

- **Plataforma:** Android
- **Framework:** Flutter
- **Linguagem:** Dart
- **Arquitetura:** ARM64
- **Versão do Dart identificada:** 3.8.1
- **Ferramenta de análise:** Blutter

## Observações

- O código recuperado não corresponde necessariamente ao projeto original completo.
- Arquivos de configuração, dependências, recursos e partes do código-fonte podem estar ausentes.
- A recuperação não garante que o aplicativo possa ser compilado ou executado novamente.

## Status do Projeto

**Descontinuado.**

O sistema deixou de ser utilizado porque a empresa não precisava mais da solução.

## Aviso

Este repositório tem como finalidade preservar o código recuperado para fins de documentação, estudo e análise. Os direitos sobre o aplicativo original pertencem aos seus respectivos proprietários.
